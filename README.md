# 🚀 RS_AI - Autonomous Sales & Order Automation Platform

A complete, 100% free, self-hosted AI sales agent for Facebook Messenger, Post Comments, and WhatsApp.

### Features:
- ⚡ **Google Gemini 2.5 Flash Brain:** Multi-modal image analysis, natural human-like salesperson voice/tone.
- 📦 **Automated Order Capture:** Extracts customer name, phone number, address, calculates delivery fees, and confirms orders.
- 💬 **Multi-Channel Inbox:** Omnichat for Facebook Messenger & WhatsApp.
- 📚 **Train Content:** Custom Q&A pairs and Facebook auto-comment replies.

### Hugging Face Deployment:
This repository is pre-configured to run on **Hugging Face Spaces (Docker)** on port `7860`.
